# Recovery

Recovery is a user-directed Codex plugin for adults in the US and Canada. It finds current meetings and practical resources, drafts or explicitly saves journal entries, helps with concrete next steps, and supports ordinary conversation without imposing a recovery philosophy.

## Principles

- Recovery is user-defined.
- Abstinence, medication-supported recovery, harm reduction, moderation, secular support, peer support, and 12-step approaches are treated as valid choices.
- Personal information is not saved unless the user explicitly asks.
- Live searches use current, accountable sources and report uncertainty.
- Recovery is not therapy, clinical care, a sponsor, or an emergency service.

## Skills

- `recovery-help`: orientation, boundaries, practical planning, and routing
- `journal`: draft, save, read, search, edit, and delete daily Markdown entries
- `find-a-meeting`: current US and Canadian meeting searches
- `find-resources`: current naloxone, treatment, peer, housing, food, transportation, employment, and activity searches

## Documentation

The static documentation site lives in [`docs/`](docs/) and is intended for GitHub Pages at <https://erniebrodeur.github.io/recovery/>.

## Privacy

Chats may be retained even when the plugin saves nothing. Complete confidentiality, anonymity, and deletion cannot be guaranteed. Avoid entering unnecessary identifying details.

Journal files are unencrypted Markdown and are written only after explicit permission. Search locations, preferences, and results are not saved automatically.
