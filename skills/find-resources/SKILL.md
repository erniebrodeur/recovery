# Find Resources

Find a small set of current services that match the user's stated needs. Do not diagnose needs, recommend a treatment plan, or rely on remembered listings.

## Required references

Read these files completely before searching:

- `../recovery-help/references/privacy.md`
- `../recovery-help/references/safety.md`
- `../find-a-meeting/references/source-quality.md`
- `references/search-protocol.md`

When this skill supplies the first Recovery response in a conversation, show the complete session warning from `../recovery-help/references/privacy.md` verbatim. Do not repeat it later in that conversation.

## Gather only needed details

Use details already present. Determine whether the request gives enough information about:

1. Resource type or practical need
2. US or Canada location, including state, province, or territory when geography matters
3. Relevant timing or urgency
4. In-person, mobile, phone, online, delivery, or no format preference
5. Material filters the user named, such as cost, insurance, accessibility, language, age, identity, medication support, or eligibility

Accept `any` or `no preference`. Ask one compact question containing only information required to run a useful search. Request a city, postal code, general area, state, province, territory, or online preference, never an exact home address.

If the user may be facing overdose, dangerous withdrawal, self-harm, violence, seizure, inability to wake or breathe, or severe confusion, stop the normal search and follow `../recovery-help/references/safety.md`.

## Search live sources

Follow `references/search-protocol.md` and `../find-a-meeting/references/source-quality.md`.

- Use live web tools for every request.
- Search the relevant US state or Canadian province or territory when geography matters.
- Prefer the responsible service operator, government, health authority, recognized coordinating directory, or regulator.
- Verify the fields that determine whether the resource is usable now. Distinguish a listed service from confirmed current capacity or an available appointment.
- Preserve provider wording for eligibility, cost, medication support, accessibility, referral, waitlist, and service format.
- Do not infer diagnosis, level of care, clinical suitability, or treatment quality.
- Do not favor paid listings, referral commissions, abstinence, 12-step, harm reduction, medication-supported recovery, or any other pathway.
- Do not contact, book, register, apply, share user information, or save criteria or results without separate explicit permission.

## Rank by fit

Rank by this order unless the user says otherwise:

1. Exact resource and pathway fit
2. Current availability or clearly stated access route
3. Location, service area, timing, and format fit
4. Eligibility, accessibility, language, and cost fit
5. Source authority and freshness

Do not rank by ideology, popularity, sponsorship, or search position.

## Report results

Return two to five strong verified options when available. For each one, include:

- Provider or program name and resource type
- Provider-stated service and eligibility
- Format, address or service area, and relevant hours
- Cost, insurance, accessibility, language, referral, registration, waitlist, or capacity details when stated
- The legitimate next access step
- Direct source link
- `Checked <date>` and the source's own update date when stated

Use `not stated` for material missing fields. Label inference and uncertainty. Never claim that a bed, appointment, dose, ride, job, or other capacity is available unless a current accountable source confirms it.

If no result can be verified, say so and offer the closest verified alternatives or one focused relaxation. Do not retain the user's location, filters, or results unless the user explicitly asks to save specified information.
