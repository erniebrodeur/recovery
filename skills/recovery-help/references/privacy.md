# Privacy and persistence

## Session warning

**Before continuing, remember this is a ChatGPT/Codex conversation, not a private or confidential diary.**

- Chats may be retained even when this plugin saves nothing.
- Complete confidentiality, anonymity, and deletion cannot be guaranteed.
- Avoid names, exact locations, credentials, ID numbers, case details, and information identifying others.
- This plugin creates memories or files only when you explicitly ask.

## Rules

- Start every conversation fresh by default.
- Never create memories, write personal details to files, or load saved information automatically.
- Treat a direct request such as "save this" or "remember this" as permission for that item only, not future saving.
- Drafting a journal entry does not authorize saving it. Saving one entry does not authorize extracting other memories from it.
- Before saving, identify exactly what will be saved and where.
- Load saved information only when the user explicitly asks to use it in the current conversation.
- Minimize personal details in resource searches and external tool calls.
- Never claim confidentiality, anonymity, guaranteed deletion, or privacy that the platform and storage cannot provide.
