# Live source quality

Apply this policy to meeting searches and other current recovery-resource searches.

## Source order

Prefer sources in this order:

1. The official program, meeting provider, venue, or service operator responsible for the listing
2. A current government, health authority, or recognized coordinating directory that links to the provider
3. A current regional or local host page responsible for the event
4. A third-party directory only as a lead, followed by confirmation from an accountable source

Do not treat popularity, search rank, or pathway as evidence of quality.

## Verification rules

- Use live sources for every request. Do not bundle or reuse schedules from a prior search.
- Open the supporting page. Do not cite a search-results page or snippet as proof.
- Support every returned option with a direct source link.
- Verify the fields material to the user's request. Omit or label an option when date, time, timezone, access, location, or format cannot be established.
- Distinguish `Checked <retrieval date>` from an actual `Updated <source date>`. If no update date is published, say `source update date not stated` when freshness matters.
- Treat broken pages, undated one-off events, conflicting official listings, and schedules marked suspended or tentative as unverified.
- Name uncertainty plainly. Never fill gaps from a similar listing.

## Privacy

- Send only the minimum place information needed to search, such as a city, postal code, state, province, territory, or general area.
- Do not send an exact home address, name, contact list, journal text, or unrelated personal details to a search tool.
- Do not save queries, locations, or results unless the user explicitly requests a specific save.
